Dynamic Benthic Pelagic Size Spectrum Model

About

This organization develops and maintains the DBPM (Dynamic Benthic Pelagic Size Spectrum Model), a tool for exploring the size structure and dynamics of benthic and pelagic communities in aquatic ecosystems. DBPM is a global application for studying climate change impacts on marine ecosystems.

DBPM is a coupled physical-ecological model that is forced with climate variables and can be applied globally (1 degree grid cells) or aggregated into Large Marine Ecosystems (LMEs) or other regions of interest.
Figure: Schematic of the Dynamic Benthic-Pelagic Size Spectrum Model (DBPM). Environmental inputs (top left) drive the size-structured dynamics of pelagic predators and benthic detritus, which in turn affect biomass flows, fish production, and ecosystem responses.

Model Inputs: Earth System Model Forcing

DBPM is driven by outputs from an Earth System Model (ESM; e.g. GFDL-MOM6-COBALT2 in the ISIMIP3a/FishMIP protocol, monthly). These variables are processed into the model's forcing — the plankton size spectrum, temperature effects, and detritus/export supply:

ESM variableDimensionsUnitsUsed for
phyc — total phytoplankton carbon3D (lon, lat, depth, time)mol m⁻³plankton size-spectrum intercept & slope; vertical biomass weights
phypico — picophytoplankton carbon3Dmol m⁻³small-vs-large phyto split → spectrum slope
thetao — ocean temperature3D°Cpelagic (water-column) temperature effect
tob — sea-floor temperature2D°Cbenthic temperature effect
tos — sea-surface temperature2D°Csurface temperature effect; export-ratio formula
intpp — integrated primary production2Dmol m⁻² s⁻¹export-ratio denominator
expc-bot — carbon export flux to seafloor2Dmol m⁻² s⁻¹export ratio → benthic detritus supply
deptho — ocean depth (bathymetry)2D (static)mdepth channel / pelagic–benthic coupling
thkcello — layer thickness3D (static)mweights for vertical integration of the 3D fields
siconc — sea-ice concentration2D%sea-ice gate on fishing effort (gridded runs only)

Plus cell area (m²) for aggregating per-cell densities. The plankton spectrum intercept and slope are derived from phyc and phypico; the export ratio ≈ expc-bot / intpp; temperature effects from thetao and tob. The depth-resolved (3D) fields are needed for the vertically biomass-weighted method; a standard method can instead use the vertically-integrated phyc-vint/phypico-vint with surface tos.

Model Repositories

All code lives in the Benthic-Pelagic-Size-Spectrum-Model GitHub organisation. The main repositories are:

  • spatial-dbpm — the dbpmr R package (the repository and the package are synonymous): the compiled-C DBPM size-spectrum engine. Unlike earlier R implementations, it adds spatial movement (behavioural and passive transport) of the pelagic size spectrum.
  • dbpmr-gridded-isimip3a — the gridded dbpmr ISIMIP3a workflow (R): runs the engine over every 1° ocean cell of a region, with biomass-weighted forcing, spatial-gravity effort, and gridded calibration.
  • dbpm_isimip3a — the ISIMIP3a input-processing pipeline (Python): Earth System Model netCDFs → the forcing data the models consume.

Conditions of use. As a condition of fair use of the DBPM model:

  • Repository. All DBPM-based work — model developments, extensions, and applications — should be hosted as a repository within this organisation, keeping the model lineage documented, reproducible, and properly attributed, and letting developments be shared across the community.
  • Co-authorship. Those applying the model to new questions or regions are asked to contact the model developers at an early stage. Where the DBPM model is central to a study and its developers contribute substantially — to model development, configuration, or interpretation — co-authorship should be offered, in line with standard authorship criteria. Otherwise, the relevant model papers (see Key Publications above) should be cited and the developers acknowledged.
